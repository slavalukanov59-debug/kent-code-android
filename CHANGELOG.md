# История изменений KENT CODE

## 0.7

- В **Действиях → Файлы** доступен просмотр рабочей папки и экспорт выбранного каталога в ZIP через системное окно Android.
- Экспорт проверяет архив после записи и показывает количество файлов, размер и SHA-256. Из архива исключаются служебные файлы, известные приложению ключи и символические ссылки.
- APK версии `0.7`, `versionCode 16`. В GitHub Actions добавлена проверка ZIP-экспорта.

## 0.6

- Mission Control показывает ожидающие, активные, приостановленные, отменённые и завершённые задачи, а также ошибки и результаты, требующие проверки. Добавлены контрольные точки, журнал, diff, открытие файлов, подтверждение проверки и экспорт.
- Память переживает закрытие приложения. Для модели выбираются сведения текущей задачи. Память можно просмотреть, экспортировать и очистить. Добавлены отчёт о повторных ошибках и отдельные копии исходников в KENT LAB.
- Пять русскоязычных разделов Red Pixel. Чат сохраняет позицию при чтении, прокручивается к отправленному сообщению и учитывает клавиатуру. Длинный код можно открыть в прокручиваемом представлении.
- GitHub использует реальные API файлов, дерева, коммитов, сравнения и Actions. Создание ветки, коммит файла и черновик PR требуют просмотра и подтверждения.
- Баланс AI-FLEX считывается из документированного ответа. Если данные недоступны, отображается «Баланс: неизвестно». В задачах сохраняются доступные входные, выходные токены и подтверждённая стоимость.
- Termux сохранил официальный RUN_COMMAND и локальный мост. Обновлены протокол, проверка результата, рабочая папка и отмена ожидания. Проверка Shizuku показывает фактический UID. AUTOPILOT ограничен локальной работой с текстом.
- APK версии `0.6`, `versionCode 15`. CI выполняет тесты, lint и сборку APK с SHA-256.

## 0.5.3 и ранее

Версия 0.5.3 добавила ограниченный повтор временных HTTP-ошибок и компактное продолжение задачи. Версии 0.5.2, 0.5.1 и 0.5.0 последовательно обновили чат, проверку ключей и Mission Control. APK и история старых релизов доступны на GitHub.
