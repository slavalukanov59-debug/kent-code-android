| Проверка | Результат |
| --- | --- |
| Java smoke | 5 из 5. Рабочая папка, ZIP-экспорт, ShellRunner, валидация ключа и повтор API. |
| Android unit | 61 из 61. Проверены GitHub-инструменты, отказ в подтверждении, ожидаемый SHA, неопределённый исход записи, лимиты API, фильтрация файлов учётных данных, проектные операции, диагностика и восстановление задач. |
| GitHub API | Через настоящий API прочитаны репозитории владельца, ветки, дерево, исходник, коммит, сравнение и результат Actions. Снимок ветки 0.7 импортирован в отдельную рабочую папку. Авторизованные операции записи из агента проверены тестовым транспортом. |
| ZIP и рабочая область | Обратный импорт старого формата с двоичным файлом и пустой папкой, SHA-256, CRC, запрет обхода рабочей области, лимиты распаковки, отклонение ссылки, проверка устаревшей цели, отмена и восстановление из корзины. |
| Задачи и данные 0.7 | Локальный тест с файлами, записанными кодом 0.7, прочитал исходный проект, чат и цель в 0.8. Неопределённая запись после прерывания требует сверки перед продолжением. |
| Локальный мост Termux | Интеграционный тест Python прошёл. Реальные процессы Linux подтвердили компиляцию C++, отказ при ошибке, раздельные stdout/stderr, код выхода, таймаут и остановку группы процессов. |
| Android lint и сборка | `lintDebug` завершился с 0 ошибок и 20 предупреждениями. `assembleDebug` прошёл. Проверен манифест APK с `ai.kent.code.red`, `0.8`, `versionCode 17`. |
| Workflow и репозиторий | `actionlint` и `git diff --check` прошли. |

Приёмка с пользовательскими ключами провайдера, проверка системного окна Android, реальный Termux на телефоне и обновление поверх установленной копии остаются проверками на устройстве. [Шаги приёмки и безопасной установки](README.md#проверки-на-устройстве)
