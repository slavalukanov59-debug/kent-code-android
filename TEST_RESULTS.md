# Проверка KENT CODE 0.6

Локальная среда — JDK 17, Gradle 8.13, SDK и Build Tools 35. Android-проверки разделены на тесты Java, сборку и отдельный запуск на эмуляторе.

| Проверка | Результат |
| --- | --- |
| Базовая версия 0.5.3 | Локальные lint и сборка APK прошли. Последний базовый запуск GitHub Actions успешен. |
| MissionStore и ChatJournal | 8 автономных JUnit прошли на JDK 17 с Android SDK 35. |
| Учёт расходов | 5 автономных JUnit прошли. Согласуются документированные схемы, проверены неизвестные данные. |
| Termux | Пройдены ShellRunner smoke, Python E2E, тесты протокола JUnit и межъязыковой запуск Java-клиента с Python-сервером в loopback. |
| Агент и рабочая папка | 9 JUnit. Проверены несколько этапов с контрольной точкой, просмотр и запись файла, отказ, запрет команд из модели, усечение ответа, безопасные пути и повтор HTTP. |
| GitHub | 10 JUnit с тестовым транспортом. Отдельно прочитаны README, дерево, коммиты, diff и Actions публичного репозитория KENT CODE. |
| Gradle и Android Manifest | `testDebugUnitTest`, `lintDebug`, `assembleDebug` прошли. Всего 34 JUnit, ошибок lint нет (14 предупреждений). |
| Проверки хоста | Прошли четыре Java smoke-теста, Python E2E локального моста, `actionlint` и `git diff --check`. |
| Android API 35 | Установлен debug APK, запущена нативная Activity, открылась последняя из 120 тестовых записей, отображены горизонтальный блок кода и неизвестный баланс. System UI виртуального устройства перестал принимать касания в этом прогоне. Взаимодействие с IME и сохранение позиции при касаниях остаются открытыми. |
| GitHub Actions и APK | Проверки PR публикуют debug APK и SHA-256. Скачивание, сверка контрольной суммы и подпись APK проверены на первом прогоне PR. |

Проверка реального Vivo X200, авторизованные запросы AI-FLEX/OpenRouter и операции записи из Android-приложения в GitHub с токеном пользователя остаются отдельными проверками. Их результаты отсутствуют в локальном прогоне.
