# KENT CODE 0.4.1 — RED PIXEL · Termux × Shizuku · OpenRouter

## Исправлено в 0.3.2: экран подтверждения команд

- Вся длинная команда отображается в прокручиваемом поле. **ОТКЛОНИТЬ** и **РАЗРЕШИТЬ** вынесены в закреплённую нижнюю панель полноэкранного окна и не исчезают при длинном тексте.
- Учитываются системные отступы и вырезы Android 15–17 (targetSdk 35): заголовок не должен перекрываться статус-баром, кнопки — жестовой панелью.
- Окно закрывается безопасным отказом при таймауте 5 минут, прерывании или отмене. Разрешение подтверждается только нажатием **РАЗРЕШИТЬ**, на одно действие.
- Следует проверить вручную на Vivo X200: очень длинные команды (4000–5000 символов), свайп до конца, кнопки внизу, отказ, разрешение, блокировка/возвращение и статусбар.

## Новое в 0.4.0: прямой OpenRouter

На вкладке **CTRL → ИИ-провайдер** выбери **OpenRouter** вместо AI-FLEX. Сохранённые ключи AI-FLEX не отправляются в OpenRouter: ключи шифруются и хранятся **раздельно** в Android Keystore. В модели укажи точный OpenRouter ID, например:

- `anthropic/claude-sonnet-5.5` — качественный повседневный код, поддерживает tool calling.
- `anthropic/claude-opus-5.5` — сложные многошаговые задачи; обычно дороже.
- `openai/gpt-6-luna` — ещё один поддерживаемый вариант.

API: `https://openrouter.ai/api/v1/chat/completions`. Получи **OpenRouter API-ключ** в собственном аккаунте и вставь *только в поле ключа в приложении*, не в чат, README, GitHub или скриншоты. Запросы оплачиваются отдельно от подписки ChatGPT. Установи разумный лимит расходов у провайдера. В настройках можно увеличить число токенов ответа до 8192, но платные лимиты / ограничения Android это не отменяет. KENT по-прежнему требует одобрения каждой команды.

Действующий AI-FLEX можно выбрать обратно. При смене провайдера чат-контекст сбрасывается; файлы сохраняются.

## Переезд с Google Play Termux на F-Droid

**ВНИМАНИЕ: Termux из Google Play (у пользователя `googleplay.2026.10.09`) несовместим по подписи с F-Droid / GitHub.** Установка поверх не работает. Сначала сделай и проверь резервную копию, только после этого удаляй Google Play Termux. Обновить полноценный Termux без миграции данных нельзя.

Чтобы сохранить рабочий проект (не весь набор токенов), открой старый Termux и выполни:

```bash
termux-setup-storage
cd ~
git -C KENT-CODE-Android status --short
tar -czf ~/storage/downloads/KENT-CODE-Android-safe-backup.tar.gz \
  --exclude='.git' --exclude='.env' --exclude='*.pem' --exclude='*.key' \
  -C "$HOME" KENT-CODE-Android
tar -tzf ~/storage/downloads/KENT-CODE-Android-safe-backup.tar.gz | head -30
ls -lh ~/storage/downloads/KENT-CODE-Android-safe-backup.tar.gz
```

Если есть другие личные проекты, архивируй их **отдельно**. Этот архив не является полной резервной копией всех данных Termux. Проверь, что там нет секретов. Сделай дополнительную копию на ПК/USB, а не полагайся на единственный архив. Не восстанавливай старый `$PREFIX/usr` из Google Play сборки в новую F-Droid.

После проверки архива вручную удали старый Termux и его плагины, поставь Termux **с официального F-Droid**: https://f-droid.org/packages/com.termux/ . Устанавливай все плагины Termux только из того же источника. Из нового Termux:

```bash
termux-setup-storage
pkg update && pkg upgrade -y
pkg install git python nodejs openssh curl -y
cd ~
tar -xzf ~/storage/downloads/KENT-CODE-Android-safe-backup.tar.gz
cd ~/KENT-CODE-Android
git init
git remote add origin https://github.com/slavalukanov59-debug/kent-code-android.git
# При необходимости: настрой gh auth login для доступа к приватному репозиторию.
```

Файлы `rish` и `rish_shizuku.dex` можно повторно экспортировать из Shizuku; после копирования в домашнюю папку использовать `chmod 700 ~/rish` и `chmod 400 ~/rish_shizuku.dex`. Старую авторизацию Shizuku после смены приложения может потребоваться подтвердить снова.

После миграции включи `allow-external-apps=true` в `~/.termux/termux.properties` и выдай KENT CODE RED разрешение `Run commands in Termux environment` — **если** новое приложение Termux его регистрирует. Ранее настроенный локальный bridge на 127.0.0.1 также остаётся допустимой альтернативой.

## Версия 0.4.1 — AUTOPILOT / без подтверждений инструментов

В **CTRL** включи **«⚡ AUTOPILOT — БЕЗ ОКОН ПОДТВЕРЖДЕНИЯ»** и нажми **«Сохранить настройки»**. Функция выключена по умолчанию. Когда она включена, **все** предлагаемые ИИ инструменты (`run_termux`, `run_adb`, `run_command`, работа с файлами) выполняются **без отдельного окна**. Запросы команд появляются в чате с отметкой **⚡ AUTO** (первые 700 символов), сверху отображается индикатор. Кнопка **«Стоп»** останавливает дальнейшие действия, но уже запущенные процессы могут продолжить работу. Отключается в CTRL; переключатель сохраняет значение между запусками.

**Риски:** ИИ может ошибиться, удалить или изменить важные файлы, выполнить команду с правами Termux или Shizuku/ADB либо прочитать приватные данные. Часть вывода отправляется внешнему ИИ-провайдеру. Используй отдельную рабочую папку и резервные копии; не открывай недоверенные проекты в AUTOPILOT. Это не ROOT и не обход разрешений Android. Собственные запросы Android могут появляться независимо от KENT CODE.

Если AUTOPILOT выключен, сохраняется поведение 0.4.0: отдельные окна подтверждения каждой команды.

Нативный Android-агент KENT CODE. Отдельный проект: **LUMI VISION не затрагивается**.

## Что работает

- Чёрно-красный интерфейс: **CHAT / FILES / BRIDGE / CTRL**.
- Онлайн AI-FLEX: выбор модели, собственный API-ключ (Android Keystore), 1–500 шагов.
- Работа с UTF-8 файлами изолированной рабочей папки; TRUSTED MODE для файлов — отдельно.
- Обычный `run_command` от UID приложения Android (по подтверждению).
- **Новый KENT BRIDGE (по умолчанию выключен):**
  - `run_termux` — команда в настоящем Termux: Python, Git, Node.js, если установлены пакеты.
  - `run_adb` — через установленный в Termux `rish` + запущенный Shizuku; Android `uid=2000(shell)`, **не root**.
  - Android-права и состояние Shizuku проверяются отдельными тестовыми кнопками в BRIDGE.
  - Каждая предложенная ИИ команда показывается полностью и требует **отдельного одобрения**. TRUSTED MODE не распространяется на команды.
- Фоновый запрос к Termux через официальный `RUN_COMMAND` intent, возврат stdout/stderr/exit code через одноразовый `PendingIntent`; ожидание ответа до 120 секунд.

## Подключение на Vivo X200 с Termux Google Play

На пользовательском Vivo X200 проверена команда `termux-info`: **`TERMUX_VERSION=googleplay.2026.10.09`**. Эта конкретная сборка не регистрирует `com.termux.permission.RUN_COMMAND` (в `dumpsys package com.termux` нет разрешения), поэтому нельзя выдать право через `pm grant` и официальный `RUN_COMMAND` в ней не работает. **Не удаляй Termux: можно потерять рабочие проекты и ключи.**

Добавлен отдельный режим: пользователь вручную запускает защищённый локальный TCP-сервер внутри Termux. KENT CODE подключается исключительно к `127.0.0.1:47883` с 48-символьным токеном. Внешние сетевые интерфейсы не используются, порт наружу не открывай. Каждая команда от AI требует отдельного подтверждения.

В Termux, где уже есть репозиторий:

```sh
cd ~/KENT-CODE-Android
git pull --ff-only
pkg install python -y
python tools/kent_bridge_server.py
```

Терминал покажет `LOCAL TOKEN`. Копируй токен **только в KENT CODE → BRIDGE**, не публикуй его в чатах или репозитории. Токен сохраняется локально в Android Keystore и `~/.kent-bridge/token`. Чтобы остановить мост, нажми Ctrl+C в Termux. Если Termux закрыт или остановлен Android, мост перестанет отвечать.

Установи APK версии 0.3.1. Во вкладке BRIDGE:

1. Найди раздел **Google Play Termux — без RUN_COMMAND** и введи токен с экрана Termux (48 символов).
2. Нажми «Сохранить токен локального моста».
3. Включи BRIDGE с отдельным подтверждением.
4. Проверь «Тест Termux: id» (UID Termux) и «Тест Shizuku: id» (`uid=2000(shell)`). Shizuku должен быть уже запущен и `~/rish -c 'id'` должен работать.
5. КЕНТ получает доступ к инструментам `run_termux` и `run_adb` только после подтверждения каждой команды.

Для Termux из F-Droid / GitHub, где `RUN_COMMAND` зарегистрирован, по-прежнему работает прямой Intent: `allow-external-apps=true`, выдача `RUN_COMMAND` приложению и запуск BRIDGE. Локальный токен имеет приоритет при его наличии; его можно очистить через пустое поле «Сохранить токен».

**Ограничения:** это не root; TCP-токен не заменяет пользовательское подтверждение; команды Termux запускаются с полными правами пользователя Termux, Shizuku даёт только ADB-shell. После каждого выполненного инструмента результат возвращается модели AI-FLEX при следующем запросе, поэтому нельзя запускать команды, которые печатают пароли или секреты. При остановке ожидания сам процесс Termux может продолжить работу.

## Границы безопасности

- **Не root**; UID Shizuku shell не даёт доступ ко всему телефону.
- BRIDGE выключен по умолчанию, дополнительно нужен системный `RUN_COMMAND` permission и включение `allow-external-apps` внутри Termux.
- На каждый shell-вызов обязательно **отдельное согласие**. Агента не следует использовать для бесконтрольного исполнения команд или работы с личными ключами.
- Команды Termux могут читать данные пользователя Termux: SSH/Git токены, файлы и данные приложений, доступные этому UID. Разрешай только понятные команды; сведения из stdout/stderr передаются внешнему серверу AI-FLEX при следующем обращении модели.
- Таймаут или кнопка остановки прекращают **ожидание в KENT CODE**, но не обязательно уже выполняемую команду Termux. Долгие процессы нужно завершать отдельно в Termux.
- AI-FLEX работает онлайн; серверные ошибки 503/524 остаются возможными. Запись файлов ограничена объёмом 250 KB.
- Привилегии другого приложения/системного раздела не предоставляются автоматически. Нет автоматической синхронизации GitHub из Android APK, API-ключ не публикуется в репозитории.

## Сборка

Java 17, Gradle 8.13, Android Gradle Plugin 8.13.2, SDK 35, min SDK 26. Зависимостей от Shizuku SDK **нет**: мост использует установленный `rish` из Termux. CI проверяет JVM smoke-tests и запускает `gradle :app:assembleDebug`. На main workflow публикует APK как pre-release GitHub Releases (в Actions artifact у аккаунта исчерпана квота). Debug-APK может менять подпись между CI-запусками; переустановка может потребовать удаления экспериментального debug-приложения **с потерей его локальных данных**.

### Проверка после сборки

1. Приложение стартует, вкладка BRIDGE открывается.
2. Termux возвращает `exitCode=0` и свой UID, Shizuku — `uid=2000(shell)`.
3. Команда из чата не запускается без отдельного подтверждения, даже в TRUSTED MODE.
4. При выключенном BRIDGE инструмент возвращает отказ без выполнения.
5. Если отключить Shizuku, `run_adb` должен сообщать об ошибке, а `run_termux` может продолжать работать.

Тестов на реальном Vivo X200 нет до установки свежего APK и ручной проверки.
