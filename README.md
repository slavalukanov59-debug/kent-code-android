# ⚡ KENT CODE — Android 0.1.0

**Нативное Android-приложение с AI-FLEX и инструментами редактирования кода.**
Отдельный проект. Ничего не меняет в LUMI VISION или других репозиториях.

## Уже реализовано

- Нативный интерфейс Android: **Чат / Файлы / Настройки**, тёмная тема.
- Подключение к **AI-FLEX** через `https://ai-flex.online/v1/chat/completions`.
- Свой API-ключ, модель и число API-шагов на задачу.
- API-ключ хранится **только на устройстве** в `Android Keystore` + AES-GCM.
- История диалога до закрытия приложения, сброс контекста, остановка задачи.
- Инструменты агента `list_files`, `read_file`, `search_text`, `write_file`, `edit_file`, `delete_file`.
- Перед записью и удалением спрашивает **подтверждение** с превью.
- Отдельная рабочая папка в приватном хранилище приложения; ручной редактор и импорт UTF-8-файлов.
- Сборка **debug APK** в GitHub Actions с артефактом для скачивания.

## Важные ограничения MVP

Это **не полная замена Codex**. В первой Android-сборке **пока нет** локального терминала, произвольных shell-команд, работы с Git-репозиториями на устройстве, синхронизации GitHub, фоновых задач и автоматического запуска тестов. Android-приложение не имеет доступа к домашней папке Termux. Не обещаем их работу до реализации. Это отдельная архитектура от Python-версии KENT CODE 3.0.

AI-FLEX работает **онлайн**. Ошибки 503/524 провайдера зависят от доступности его моделей. Количество шагов ограничено настраиваемым параметром от 1 до 100, чтобы избежать бесконечных платных циклов. Чтение файлов до 120 KB и запись до 250 KB на файл. Эти ограничения MVP будут расширяться после тестов.

## Готовим GitHub и APK со смартфона

1. Скачай архив `KENT-CODE-Android.zip` в `Download`.
2. В **Termux** выполни:

```bash
pkg install git gh unzip -y
termux-setup-storage
cd ~
unzip -o ~/storage/downloads/KENT-CODE-Android.zip
cd KENT-CODE-Android
```

3. Авторизуй GitHub CLI **через браузер**, без вставки токенов в чат:

```bash
gh auth login -h github.com -p https -w
```

4. Создай **НОВЫЙ приватный** репозиторий `kent-code-android` и отправь код:

```bash
bash publish.sh
```

5. В новом репозитории открой **Actions → Android APK → последний запуск**. После успешной сборки в разделе **Artifacts** появится `KENT-CODE-v0.1-debug-apk`. Скачай архив артефакта, извлеки `app-debug.apk` и установи на Vivo X200.

В рабочем процессе нет ключа API. Его вводят **внутри приложения после установки**. Не добавляй `local.properties`, ключи и секретные токены в GitHub.

## Технически

- Java 17, Android Gradle Plugin 8.13.2, Gradle 8.13, Android SDK 35, min SDK 26.
- Нет сторонних Java/Kotlin библиотек; интерфейс на штатном Android SDK.
- GitHub Actions: checkout → JDK 17 → Gradle → проверка локальных файлов → Android SDK → `assembleDebug` → artifact.
- Сетевые запросы только `HTTPS`. Настоящий ключ не присутствует в исходниках, `.git` или Actions.
- Проверка работы с файлами `tests/WorkspaceSmokeTest.java` может запускаться JDK 17 без Android SDK.

## Безопасность

- В приложении разрешено работать только с файлами его рабочей папки; попытки `../` блокируются.
- Секретные файлы (`.env`, ключи, `credentials.json` и т. п.) закрыты для AI-инструментов.
- Перед любой записью/удалением агенту нужно разрешение пользователя.
- Учитывай, что отправленный в AI-FLEX текст файлов окажется на стороннем сервере. Не импортируй приватный код/секреты, если не согласен с такой передачей.
- Код от модели — **недоверенный**. В этом MVP он не выполняется автоматически.
- Если раньше публиковал API-ключ в чатах или скриншотах — перевыпусти его до настройки приложения.
