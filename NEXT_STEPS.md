# Дальнейшая проверка KENT CODE 0.6

1. На Vivo X200 проверить ввод с клавиатурой, системные отступы, прокрутку старого чата, поворот экрана, ограничения OriginOS и восстановление после принудительного завершения процесса.
2. Проверить запросы с аккаунтом пользователя AI-FLEX и OpenRouter. Зафиксировать поля `usage`, наличие `remaining` и ошибки тарифа для доступных ключей и моделей. Данные авторизации хранить в настройках Android.
3. На тестовом репозитории проверить создание ветки, коммита и черновика PR из Android с минимально необходимыми правами токена. Проверить отказ при смене SHA.
4. На Vivo проверить локальный сервер в Termux Google Play, официальный RUN_COMMAND при наличии разрешения и вывод `id` у настроенного Shizuku/rish.
5. Перед распространяемым обновлением определить поддерживаемый ключ подписи. APK разных CI-запусков может получить разные debug-подписи. Проверить подпись прежней и новой сборки до установки поверх существующей. Для установки из GitHub доступен debug APK и контрольная сумма.
6. Для публикации в Google Play запланировать проверку target SDK 36, Android 16 и требований магазина на дату подачи. [Требования Google Play](https://developer.android.com/google/play/requirements/target-sdk)
